# OPENINVEST MASTER ENGINEERING SPECIFICATION

# DOCUMENT 14

# MATHEMATICAL ENGINE, PORTFOLIO CALCULATION & FINANCIAL MODEL

Version: 1.0

Status: Approved

Priority: Critical

---

# PURPOSE

Настоящий документ определяет единственный допустимый математический движок OpenInvest.

Любой другой способ расчета считается ошибочным.

Все вычисления должны производиться исключительно на Backend.

Frontend никогда не рассчитывает инвестиционные показатели.

---

# PRINCIPLES

Система должна показывать:

не красивые цифры,

а реальные деньги.

Пользователь должен понимать:

* сколько он заработал;
* сколько потерял;
* сколько съела инфляция;
* сколько он получил дивидендов;
* сколько налогов уже заплатил;
* сколько налогов еще придется заплатить;
* сколько составляет его настоящая годовая доходность.

---

# GLOBAL PORTFOLIO MODEL

Стоимость портфеля состоит из пяти независимых компонентов.

```

+

Cash

+

Accrued Coupon Income
```

# AVERAGE COST

Для акций используется

Weighted Average Cost.

```
New Average

=

((OldQty × OldAverage)

+

(NewQty × NewPrice))

/

(TotalQty)
```

---

SELL

не изменяет Average Cost.

# WHAT IS NEVER ALLOWED

Запрещено:

использовать простую доходность;

складывать проценты;

игнорировать комиссии;

игнорировать налоги;

игнорировать инфляцию;

игнорировать НКД;

строить график только по текущему количеству акций.

---

# HUMAN FRIENDLY MODE

Все сложные показатели сопровождаются объяснением.

Например:

```
XIRR

11.82%

Что это значит?

Если бы ваши деньги работали одинаково эффективно каждый год,

вы бы получали 11.82% годовых.
```

# CODEX REQUIREMENT

Любая новая функция должна проходить обязательную проверку:

1. Не нарушает ли XIRR.
2. Не нарушает ли Average Cost.
3. Не нарушает ли расчет налогов.
4. Не нарушает ли расчет инфляции.
5. Не нарушает ли расчет покупательной способности.
6. Не ухудшает ли производительность Backend.
7. Не увеличивает ли сетевой трафик без необходимости.
