# 1. DOCUMENT PURPOSE

Данный документ определяет архитектуру безопасности OpenInvest.

Это один из основных документов проекта.

Никакой модуль не может быть реализован в обход требований данного документа.

Безопасность является частью архитектуры, а не дополнительной функцией.

# 3. НАША ГЛАВНАЯ КОНКУРЕНТНАЯ ОСОБЕННОСТЬ

Большинство инвестиционных сервисов собирают максимально возможное количество данных.

OpenInvest собирает минимально необходимое количество данных.

Пользователь полностью контролирует:

• что хранится;

• где хранится;

• сколько хранится;

• когда удаляется;

• кому отправляется.

# 4. PRINCIPLES

## Principle 1

User owns data.

Не компания.

Не разработчик.

Не AI.

Не сервер.

---

## Principle 2

Minimal Collection.

Если функция может работать без персональных данных —

персональные данные запрещено запрашивать.

---

## Principle 3

Explicit Consent.

Любое сохранение личной информации требует отдельного согласия.

---

## Principle 4

Delete Anytime.

Любые данные должны удаляться одним действием пользователя.

---

## Principle 5

Transparency.

Пользователь всегда знает:

что хранится;

когда хранится;

зачем хранится;

когда будет удалено.

# 8. TAX PROFILE

Три режима.

---

## Mode A

No Tax Profile

OpenInvest формирует пустую декларацию.

Пользователь заполняет все самостоятельно.

Никакие данные не сохраняются.

---

## Mode B

Temporary Tax Profile

Пользователь вводит:

ФИО

ИНН

адрес

паспорт

система генерирует XML/PDF

отправляет на email

сразу удаляет информацию.

---

## Mode C

Persistent Tax Profile

Пользователь разрешает хранение данных.

Все поля можно изменить.

Все поля можно экспортировать.

Все поля можно удалить.

По умолчанию выключено.
