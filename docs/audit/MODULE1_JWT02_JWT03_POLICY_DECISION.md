# Module #1 — JWT02 / JWT03 policy
**Problem / Root Cause:** The verifier does not compare future `iat`; Go JSON decoding permits repeated recognized claims, so stronger historical test expectations differed from the contract.
**Risk:** Signed future-iat tokens can be usable until expiry; issuer/key/clock compromise, stateless logout lifetime and cross-parser differences remain explicit residuals.
**Alternatives:** Option B proposed mandatory integer `iat`, 60-second skew and timestamp/expiry consistency; duplicate-claim rejection would require a separate parser policy; neither is authorized here.
**Decision:** Owner-approved JWT02 Option A retains the verifier and mandatory `exp`; JWT03 remains accepted informational behavior; [owner approvals](https://github.com/AsifAbbasov/OpenInvest/blob/3e2ca51f761a1f8ea92370f666cf636b9de3b600/docs/audit/MODULE1_OWNER_CLOSEOUT_APPROVALS_V1.md).
**Rationale:** Preserve the approved identity/signature/expiry contract without inventing a new issuer/time/parser requirement; historical RED assertions are not relabeled PASS.
**Implementation:** No JWT02/JWT03 code change; [full policy, Option B semantics and evidence](https://github.com/AsifAbbasov/OpenInvest/blob/3e2ca51f761a1f8ea92370f666cf636b9de3b600/docs/audit/MODULE1_JWT02_JWT03_POLICY_DECISION.md) preserves all requirements and alternatives; [PR268](https://github.com/AsifAbbasov/OpenInvest/pull/268) MERGED at `3e2ca51f761a1f8ea92370f666cf636b9de3b600`.
**Verification:** Technical acceptance PASS and [post-merge CI 38758661473](https://github.com/AsifAbbasov/OpenInvest/actions/runs/38758661473) SUCCESS 10/10; historical [future-iat RED](https://github.com/AsifAbbasov/OpenInvest/actions/runs/38636806790/job/116101936984) remains RED, not a passing stricter-policy suite.
**Limitations:** No verifier-enforced maximum remaining lifetime; ordinary access lifetime is 15 minutes, logout revokes refresh/session material rather than immediate access JWTs; no universal cross-parser/signing-key safety guarantee.
**Status:** JWT02 Option A APPROVED; JWT03 DOCUMENTED_ACCEPTED_BEHAVIOR / INFORMATIONAL; new recovery/revocation changes and deployment NOT AUTHORIZED; formal Module #1 closure unchanged.
